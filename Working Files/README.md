Nimbus — Responsive Pricing Table

A modern, responsive SaaS pricing interface designed to make subscription plans simple, clear and accessible.

Overview

Nimbus is a responsive pricing table featuring three subscription plans: Free, Pro and Enterprise.

The interface uses an elegant visual identity, refined typography, subtle animations and interactive billing options to create a polished user experience.

Features

- Three subscription plans: Free, Pro and Enterprise.
- Interactive monthly/yearly billing toggle.
- Responsive desktop, tablet and mobile layouts.
- Animated pricing cards and interactive buttons.
- Smooth entrance and scroll-reveal animations.
- Elegant typography using Bree Serif, DM Sans and Caveat.
- Custom colour palette and reusable CSS variables.
- Reduced-motion accessibility support.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

Running Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run:

python3 -m http.server 8000

4. Visit http://localhost:8000 in your browser.
